# spread

**Spreadsheet viewer in Rust/GPUI** — a high-performance spreadsheet rendering engine built with the Zed GPUI framework.

## What This Gives You

- **GPU-accelerated rendering** — GPUI-backed spreadsheet display
- **Large dataset support** — handles millions of cells without lagging
- **Rust performance** — native speed for cell computation and rendering
- **Keyboard-driven** — vim-like navigation for power users

## Quick Start

```bash
cargo run -- /path/to/spreadsheet.csv
```

## How It Fits

Visualization tool for the SuperInstance ecosystem. Renders `polln` tile data and `conservation-spectral` results in a performant, native spreadsheet view.
